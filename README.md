# Proyecto: Expedientes Académicos

## Descripción del Proyecto
Este proyecto desarrolla una **Bases de Datos** con datos de un claustro y varias clases.

Contiene el historial académico de sus alumnos.

## Tecnologías Utilizadas
* **Lenguaje:** Python
* **Librerías:** `pandas`, `psycopg2`.
* **Visualización de Datos:** `pgAdmin 4`.
* **Hosting:** `Render` 
* **Entorno de Desarrollo:** Visual Studio Code y Jupyter Notebooks.

## Ejecución Rápida
```bash
# Ejecutar el análisis completo
python main.py
```
